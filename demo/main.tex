\section{Introduction}

Welcome to the live LaTeX editor demo. This document is split across
multiple files with \texttt{\textbackslash input} and
\texttt{\textbackslash include}, exactly like a real project.
Double-click any paragraph, formula or table to edit it.
Your changes are written straight back into the \texttt{.tex} files ---
no compile step, no round trip to a PDF viewer.

The editor understands sectioning, paragraphs, inline math like
$e = mc^2$ and $\alpha \beta \gamma$, display formulas, lists, tables
and figures. Everything it does not render natively shows up as a
visible chip instead of silently disappearing.\footnote{Footnotes
render inline in gray parentheses.} testtest
